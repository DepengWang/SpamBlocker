## P3：通用接入完成（本轮确认范围）

- 用户明确确认“暂时没有，先完成通用接入”；腾讯、360、电话邦没有伪造接入，保留待授权状态。
- 新增统一身份/证据模型，保留每个来源的字段、风险、查询时间与成功/无结果/错误/超时状态。
- 支持可配置 HTTPS GET/POST、请求头认证、号码模板、JSON 点路径/数组下标、业务成功码和风险枚举映射。
- 最多 6 个来源、全局网络并发最多 3；总超时默认 3 秒，允许 250–5000 ms；响应上限 256 KiB，取消时断开连接。
- 离线信息先显示，线上补充身份和缺失字段；按配置顺序合并，不按网络返回先后覆盖。冲突保留证据并警示，不输出安全结论。
- 联系人来电不自动上传，在线来源默认关闭；新增结果只提示，不自动拦截。原有 Instant Query / PhoneBlock 规则保持不变。
- 缓存使用原 SQLite 数据库的新增表 `cn_identity_cache`，幂等建表，不占用上游 DB_VERSION，不修改历史及规则表；按号码/来源配置指纹隔离，最多 2000 条。
- 身份默认 7 天、标记 1 天、确认无结果 6 小时、错误退避 2 分钟；可配置。错误不作为阴性结果；混合身份/标记响应使用较短有效期。
- 设置 → 即时查询 → 号码识别 → 配置，支持保存、查询测试和清空缓存；配置纳入现有备份/恢复，查询缓存不备份。
- 使用说明与接入示例：`Docs/cn-identity-api.md`。

### Tmini 新站付费聚合标记 API

- 以 `https://api.tmini.net/detail/1` 为准，预设切换到 `/apis/checkmark`，认证参数 `key`、号码参数 `phone`，按 `code=200` 解析，并从 `results[].tags[].name` 聚合标签。
- 增加 JSON 数组通配符路径支持；余额不足等非 200 业务结果仍为错误，不缓存为无标记。
- 一次真实测试查询 `13812093399` 成功，返回地区“江苏无锡 移动”、`isMarked=false`，11 个平台均“未标记”，没有标签。按页面计费规则该成功查询扣 300 积分；本轮未重复调用。
- 注意：该付费接口文档要求 Key 只在服务端使用。应用直连是用户自担设备密钥暴露风险的个人配置方案，不将用户提供的 Key 硬编码进源码或 APK。
- 已实现本地优先和永久缓存：原 `phone_number` 有标记时跳过 Tmini；否则只要应用私有 `marked.db` 工作副本内 `tmini_mark_cache` 有记录就不请求接口。成功标记及成功无标记都不自动过期、不淘汰；设置页“清空缓存”会同时清除通用缓存和 Tmini 永久缓存。旧版本缓存升级为永久缓存；接口错误不作为无标记保存；原始 APK 资源保持不变。该独立表可供未来线上备份功能纳入，目前尚无线上备份实现。
